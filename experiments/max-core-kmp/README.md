## تجربة واجهة الجلسة على عيّنة فقط

استعمل دائمًا **المخطط الموثوق المرفق** لا مخططًا يأتي من وثيقة مشروع. في متصفح يدعم ESM:

```js
import { MaxSession } from './max-core.mjs';
const s = new MaxSession(schemaText, fixtureText);
s.edit(JSON.stringify({op:'split', id:'cA', atUs:3000000,
  rightId:'cB', expectedRevision:0})); // returns '1'
const scene = JSON.parse(s.render('3000000')); // null outside [0,D)
const projectAfter = JSON.parse(s.snapshot());
```

نظير JVM هو `core.Handle(schemaText, fixtureText)` بنفس الثلاثة `edit`, `snapshot`, `render`. عند الفشل لا تعدّل الحالة؛ `trace` هو سطح إثبات يلتقط الأخطاء والمخرجات مع الحالة. لا يُعرّف ABI إنتاج للأخطاء غير المعروفة، ولا تُرسل Long عبر Number في واجهة وقت العرض. عند تمرير الأمر JSON يجب أن تكون الأزمنة والمراجعات أعدادًا صحيحة ضمن حدود v1 الآمنة. الجلسة لكاتب واحد فقط وليست CAS موزعة.

ترتيب الطبقات من الخلف للأمام؛ `order` لا يقبل إلا تبديلًا كاملًا لنفس المعرّفات. split يحتفظ باليسار ويستخدم rightId جديدًا، ولا يغيّر assetId أو زمن الطبقات. `putKey` يستبدل عند زمن مطابق لا عند زمن قريب، وإلا يضيف بالترتيب؛ `removeKey` عند حذف آخر مفتاح يستبقي قيمته كأساس. وقت مفاتيح الفيديو بزمن الأصل ووقت مفاتيح الطبقة محلي. المدة `[inUs,outUs)`؛ المؤثرات مرتبة كما في تنفيذ الويب المرجعي، و`RenderSpec` **بيانات وتعليمات** فقط وليست إطار فيديو. التراجع والإعادة يزيدان المراجعة ولا يعيدان رقمًا قديمًا. الأوامر ناجحة في الذاكرة فقط.

## إعادة التشغيل

من **هذا المجلد** على Linux، JDK 17، Node 22، Python 3، Chrome حديث وnpm، مع اتصال لتنزيل أدوات البناء أول مرة:

```sh
./gradlew --no-daemon jvmJar runtimeDeps compileProductionExecutableKotlinJs
mkdir -p proof/records
bash tools/run-proof.sh
# اختياري: على محاكٍ مؤقت فقط، Android 15 / API 35 وأدوات SDK/D8 وadb:
bash tools/android.sh
```

`tools/android.sh` يشغّل JAR بعد D8 في `/data/local/tmp/max-kmp-proof` على محاكٍ فارغ؛ لا يثبّت APK ولا يصل إلى مجلدات التطبيقات. احذف تلك النسخة المؤقتة أو أعد إنشاء المحاكي قبل إعادة الاختبار (يُجعل dex للقراءة فقط). مسار JVM `java -cp 'jvm/*' probe.Probe fixtures result.json` في التسليم. JAR رفيع يحتاج JARs التشغيل المجاورة له؛ dex المرفق **ليس APK**. حزمة JS تتضمن مكتبات تشغيلها؛ ملف gzip قياس أو أصل للنشر بترميز gzip، وليس التنزيل المستخدم عند قياس زمن التحميل.

## حدود الدليل

تستهلك التجربة الـJSON الموثوق في ذاكرة العملية وتتحقق من كل مرشح بالكامل قبل الإقرار. هذا مقصود لتقليل خطر خطأ دلالي في التجربة، وليس مسار تحرير لحظي مُحسّنًا. القياسات التفصيلية لكل دفعة موجودة في الحزمة. الاختبارات لا تثبت أداء هاتف منخفض الذاكرة أو تكافؤ بكسلات أو تصدير أو صلاحية استيراد ملفات غير موثوقة. لم يُثبّت هذا الكود في أيّ من المحررين.
