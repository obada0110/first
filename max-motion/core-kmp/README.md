# MAX EDITOR shared project core

Production-owned Kotlin Multiplatform module consumed by the Android application. `commonMain` contains the Project Contract v1 validator/model, timeline clock, edit session, stable-ID commands and render intent. It has no Flutter, Android, DOM, decoder, renderer, or storage dependency. Hosts provide a durable commit callback; Android currently binds that callback to the existing atomic `single-v1.json` checkpoint behind a debug-only build flag. When enabled, the debug application ID is suffixed `.phase3a`, isolating its private files, permissions and preferences from the installed product package. The app also builds the JVM and JS targets to guard cross-platform compilation.

Contract and operation details remain in `../contract/README.md`. The integration uses `schemaVersion: 1` unchanged. Source tests and cross-target probes are maintained separately in `../../experiments/max-core-kmp`; their Gradle source set references this production module so there is one shared edit engine, not a duplicated laboratory implementation. Experimental UI is disabled by default and in every release build.
