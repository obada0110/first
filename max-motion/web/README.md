# MAX MOTION — نسخة الويب المحفوظة

هذا المجلد نسخة مستقلة ومحفوظة من محرر الويب، وتشمل صفحة التشغيل والواجهة والملفات المحلية والاختبارات والوسائط التجريبية. لا يحتوي على تطبيق Android.

## ما الموجود هنا؟
- `index.html` نقطة دخول محرر المتصفح.
- `editor.js`, `composition.js`, `effects.js`, `studio.js` منطق التحرير والتركيب والمؤثرات.
- `studio.css` و`interface/` للتصميم ولوحة الاستوديو والمكتبة والقوالب.
- `media/` مواد العرض المحلية.
- `tests/` اختبارات الويب.
- `test01.json` نموذج تاريخي قديم، وليس مدخل التطبيق الحالي.

## التشغيل
خادِم ملفات محليًا من هذا المجلد (المتصفح يحتاج HTTP لبعض خصائص الوسائط):

```sh
cd max-motion/web
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000/`. لا تستخدم مسار `file://` للاختبارات التي تحتاج مصدرًا محليًا للوسائط.

## ملاحظة الحفظ والتوافق
هذه نسخة مجمّدة للحفظ والفصل عن عمل Android، نُسخت من مصادر الويب الموجودة في جذر `max-motion/` عند commit `89cf0cb`. تُركت ملفات الجذر كما هي لتجنّب كسر إعداد GitHub Pages والاختبارات وسجلات النقل الحالية. لذلك عند استئناف تطوير الويب لاحقًا، حدّد مصدر الحقيقة أولًا ثم حدّث النسختين/مسارات النشر معًا؛ هذا المجلد نسخة محفوظة وليس مرآة تلقائية.
