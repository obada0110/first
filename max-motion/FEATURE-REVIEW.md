# Max Motion 03 — سجل مراجعة الأدوات

**طريقة العمل:** مراجعة وثائق المنشئ أولًا، ثم الشروحات عند غياب توثيق تفصيلي، ثم اختيار خصائص تناسب محرّر ويب محلي خفيف. هذه مقارنة مكتبية وليست تجربة مباشرة لكل إصدار مدفوع أو مطابقة كاملة للتطبيقات. المطر والجليد رسومات إجرائية أصلية ولا تحتاج تنزيل مكتبة مؤثرات.

| الأداة | أسئلة المقارنة وقرار التنفيذ |
|---|---|
| الكروما | التقاط اللون وضبط النطاق كما في شروحات CapCut وInShot؛ نعومة الحافة والتنظيف وعكس التحديد من خصائص دليل Alight Motion. استبدال بخلفية لون موحّد، لا عزل تلقائي للأشخاص ولا فيديو ألفا. |
| التمويه | تأثير ناعم كامل أو منطقة دائرية: قوة، مساحة، ومركز أفقي ورأسي. لا تتبّع تلقائي للوجه. |
| التوهّج | فصل المناطق الساطعة وإعادة مزج هالتها: قوة وانتشار وعتبة ولون. ليس نسخة من حزمة فلاتر تجارية. |
| المطر | ربط الحركة بزمن المصدر كي تتكرر في المعاينة والتصدير. كثافة وسرعة وريح ووضوح. |
| الجليد | تكييف طلب المستخدم لحدود الكادر: امتداد، بلورات، قوة ولون، مع إبقاء وسط الصورة واضحًا. لا نفترض أن نفس التأثير موجود بالاسم والإعدادات نفسها في التطبيقات الثلاثة. |
| تمويه الحركة | طول واتجاه كما في دليل Directional Blur، مع مزج مستقل. تمويه مكاني لا تحليل بصري لحركة الأجسام. |
| الضوء | مقارنة منزلقات إضاءة CapCut وInShot مع ضبط Exposure/Gamma/Offset؛ التعريض للسطوع العام، وغاما للدرجات الوسطى وإزاحة للسطوع الأساسي. |
| التباين | منزلق موقّع مع نقطة ارتكاز قابلة للضبط. |
| التشبّع | قيمة للتشبّع العام وقيمة للحيوية التي تؤثر أكثر في الألوان الأقل تشبّعًا. |
| حرارة اللون | دافئ/بارد وأخضر/أرجواني في نفس اللوحة. |

### الاختبار
- مُدخل محلي مرسوم مع جزء أخضر وبقعة ساطعة وتفاصيل رفيعة ودرجة صوت ثابتة. `tests/fixture.py` يصنع الملف ولا يرسل بيانات.
- `tests/effects.cjs` يشغّل واجهة الموبايل في Chromium، ويجرّب تمكين ومقارنة ومعاينة وتصدير وإزالة الأدوات العشر، ثم التراجع وانتقال المؤثرات عبر القص.
- `tests/check.py` يفك ترميز الملفات ويقيس تبدل اللون، حدّة الحواف، الإضاءة، حركة المطر وأثر الجليد على الأطراف، ويفحص الصوت لكل تصدير. اختبرنا على متصفح تجريبي، لا على هاتف المستخدم فعليًا.
