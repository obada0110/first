# مسار تحرير فيديو واحد على Android

ماذا يختبر هذا التسليم؟ اختيار ملف حقيقي، قراءة خصائصه، معاينة المصدر، حفظ تحديد غير مدمر، ثم إنتاج MP4 مستقل. ليس المطلوب لقطة لزر تصدير؛ الدليل هو الملف المنشور في التخزين العام ونتيجة فكّه ومقارنته بأصله. لا يوجد في هذه الحزمة محرك طبقات أو تعديلات للويب.

**النتيجة:** اكتملت اختبارات القبول على محاكي Android API 35. [APK تجريبي](https://github.com/obada0110/first/releases/download/single-preview-44895793489/MAX-EDITOR-single-debug.apk) · [ملفات المصدر المحدث](https://github.com/obada0110/first/raw/77cb43b3ea2d788b558197152776d80662bb2264/docs/max-motion/MAX-EDITOR-single-source.zip) · [سجلات وفيديوهات الاختبار](https://github.com/obada0110/first/releases/download/single-preview-44895793489/handoff.zip).

## تجربة الهاتف

١. افتح MAX EDITOR واضغط «اختيار فيديو من الملفات». يفتح منتقي Android الرسمي. تُعرض دقة العرض بعد الدوران، ومدة المصدر، ومعدل الإطارات إن أعلنه مسار الفيديو، ووجود الصوت.

٢. شغّل المصدر أو أوقفه واسحب مؤشر الزمن. اختر بداية ونهاية عند المؤشر، أو أدخل الحدين بالمللي ثانية ثم اضغط «حفظ النطاق». تظهر مدة الجزء المحدد؛ تتغير بيانات المشروع لا بايتات الأصل.

٣. اضغط «تصدير الجزء المحدد». يبقى الملف خاصًا أثناء التحويل والفحص. على Android 10 فأحدث تُنشر النسخة تحت `Movies/MAX EDITOR`؛ وعلى الإصدارات الأقدم المدعومة يختار المستخدم مجلدًا. الإلغاء لا يحذف الأصل.

٤. عند إعادة الفتح تُقرأ اللقطة ثم يُفتح المرجع بإذن القراءة المحفوظ. إذا تعذّر الوصول إلى المصدر تبقى اللقطة وتظهر رسالة. اختيار مصدر آخر بنجاح يستبدل المشروع المحلي الحالي، وليس ملف الفيديو الأصلي.

# من الزر إلى ملف MP4

| الجزء | التنفيذ وحدوده |
|---|---|
| Flutter | 3.38.3 مع واجهة عربية افتراضيًا وإنجليزية من الإعدادات. قناة `max_editor/single/v1` تفصل أحداث الاستيراد والمعاينة والتحديد والتصدير عن العرض. |
| الوصول | `ACTION_OPEN_DOCUMENT`، إذن URI ثابت للقراءة فقط، لا إذن قراءة التخزين كله. MediaExtractor يقرأ المسارات وMediaMetadataRetriever يقرأ الدوران. لا تُخزّن نسخة ثانية من المصدر. |
| المعاينة | ExoPlayer وPlayerView من AndroidX Media3 **1.6.1**. سطح TextureView يحترم أبعاد الفيديو، والساعة من موضع المشغّل نفسه. المعاينة للمصدر كله، والتصدير للنطاق المحفوظ فقط. |
| المشروع | نفس `ProjectV1` و`AtomicCheckpoint` المعتمدين، بلا تعديل للمخطط. مسار واحد وقطعة واحدة. `inUs/outUs` بالنطاق نصف المفتوح. ربط `assetId` بـ URI في إعدادات خاصة منفصلة؛ هذا الربط ليس نموذج تحرير ثانيًا. |
| التصدير | Media3 Transformer 1.6.1، قص بحدود µs وهدف حاوية MP4 وفيديو H.264 وصوت AAC إن وُجد. التقدم من Transformer، وحالة غير رقمية عند عدم إتاحة النسبة. لا مسار صوت مستقل أو تغيير متعمد في سرعة التشغيل. |
| النشر | فحص المدة ووجود الصوت وإمكانية فك إطار من الملف المؤقت. النشر باسم فريد؛ على API 29+ لا يُكشف الملف في المكتبة حتى اكتمال نسخه. خطأ النظام أو نفاد المساحة يُبلّغ، والملف الجزئي يُنظَّف عند الإلغاء أو الخطأ المتوقع. |

الإعدادات الموروثة: minSdk 24، compileSdk 36، JDK 17، Kotlin 2.2.20، Gradle 8.14 وAGP 8.11.1. استُخدمت مكتبة JSON 1.8.1 نفسها في التطبيق. لم تُحدّث اعتماديات Flutter بالجملة.

# نتائج القبول

اختُبرت النسخة `aa4db10` على محاكي API 35 ‏x86_64 بملفين مُولّدين، طول كل منهما ٦ ثوانٍ عند ٢٤ إطارًا/ثانية. الأفقـي ٣٢٠×١٨٠ بصوت ٦٦٠ هرتز، والعمودي يحمل دوران عرض ٩٠° وبلا صوت. تحقّق ffprobe من دوران مدخل الاختبار نفسه قبل التنفيذ.

| اختبار إلزامي | النتيجة الفعلية |
|---|---|
| ١ و٢ — الاختيار والتشغيل | أعاد منتقي النظام الملفين. اختُبرت أوامر التشغيل والإيقاف والتنقل وساعة ExoPlayer. ظهرت إطارات نمط الاختبار الملونة في معاينتي الأفقي والعمودي. |
| ٣ و٤ — القص والمدة | رُفض تحديد ٢٠ ms، وحُفظ النطاق `[1.000,3.500)` من المصدرين. الهدف ٢٫٥٠٠ ثانية؛ مدة حاوية الأفقي `2.520041 s` (+٢٠٫٠٤١ ms)، ومدة العمودي `2.500000 s` (لا فرق مقاس). الأولى ضمن حد الاختبار ١٣٠ ms وليست مطابقة حرفية. |
| ٥ و٦ — الصوت والصمت | فُكّ أفقيًا مسار صوت حقيقي إلى PCM؛ تردّد النغمة المقاس ٦٦٠ هرتز مع سعة غير صامتة. لم يعثر الفاحص على أي مسار صوتي في الناتج العمودي. لم يُختبر بمكبر هاتف فعلي. |
| التشغيل والاتجاه | أُعيد استيراد كل MP4 منشور وتشغيله داخل التطبيق، وتحقّق الاختبار من تقدّم موضع التشغيل ووجود بكسلات النمط في الشاشة. فُتح ناتج أيضًا بمشغّل النظام. فكّ FFmpeg الملفين كاملين دون خطأ؛ أبعاد العرض ٣٢٠×١٨٠ و١٨٠×٣٢٠. |
| دقة المحتوى | قورنت إطارات الناتج عند ٠٫٢٥ و١ و٢٫٢٥ ثانية بإطارات الأصل عند الزمن نفسه +١ ثانية بعد تطبيق الدوران. متوسط فروق RGB على مقياس ٢٥٥: أفقي `2.56 / 3.38 / 3.37` وعمودي `1.99 / 2.94 / 3.12`؛ حد الاختبار ١٢ لكل عينة. |
| ٧ — الإغلاق والاستعادة | بعد إيقاف العملية فعليًا وإعادة تشغيل APK العادي، تطابقت اللقطة: مراجعة ١، `inUs=1425000` و`outUs=6000000`. |
| ٨ و٩ — الفقد والفشل والإلغاء | رُفض ملف تالف وبقي المشروع السابق. بعد نقل مصدر تجريبي خارج التخزين المتاح فشل التصدير وظهرت رسالة فقدان المصدر دون انهيار؛ تطابقت اللقطة بعد إعادة الفتح. نجح أمر الإلغاء ثم تصدير جديد؛ بقي ملفان نهائيان فقط للنجاحين. |
| ١٠ — الأصل | طابقت بصمة SHA-256 لكل ملف على الجهاز قبل التصدير وبعده بصمة عينة المضيف. القيم الكاملة محفوظة في JSON المرفق. |

نجحت فحوص Flutter والبناء واختبار اللغة و٧ اختبارات العقد وفحص توافق الويب. [سجل CI الكامل](https://github.com/obada0110/first/actions/runs/44895793489) · [نتائج جهاز العقد XML](https://github.com/obada0110/first/actions/runs/44895793489/artifacts/14703733822).

# المشكلات والقيود ونقطة التوقف

خلال التحقق فتحت أتمتة الاختبار معاينة منتقي الملفات بدل إعادة المستند؛ صُحح الاختيار بالاسم. مخرَج توليد عينة عمودية أولى لم يحمل مصفوفة الدوران؛ أضيف فحص للمدخل. لقطة أفقية مبكرة كانت سوداء، فلم تُحتسب دليلًا؛ أعيد الالتقاط أثناء التشغيل بعد تركيب سطح العرض، وأضاف الاختبار شرط ظهور بكسلات النمط في الصور الأربع. في التشغيل النهائي نجحت هذه الشروط كلها.

حجم APK التجريبي الجامع للمعماريات **١٤٩٬٠٤٨٬٤٩٢ بايت** (١٤٩ MB تقريبًا)، أكبر من هدف أقل من ١٠٠ MB. ليس هذا حجم إصدار إنتاج موقّع أو مضغوط حسب معمارية الهاتف. لا ندّعي تحقيق هدف الحجم أو اختبار 1080p60 بهذه العينات الصغيرة.

- لا هاتف فعلي في بيئة العمل، ولا اختبار POCO X5 Pro. نتائج المحاكي لا تثبت الأداء أو دعم كل مشفر أو إصدار Android. لم تُختبر كل فئات التخزين السحابي أو كل الصيغ أو HDR.
- يستخدم التصدير ملفًا مؤقتًا ثم نسخة نهائية. يلزم توفر مساحة، وقد يُبلّغ Android عن نفادها أثناء الكتابة. لم يُملأ قرص هاتف فعلي، ولا يُدّعى اختبار قطع الطاقة. قتل عملية التطبيق أثناء التصدير ليس إلغاءً منظمًا ولا توجد إعادة استئناف للتصدير في الخلفية.
- `revision` وآخر لقطة يستمران بعد الإغلاق. لا يبقى تاريخ التراجع أو الإعادة بعده، ولا زران جديدان لهما في هذه الشاشة. لا يتضمن الملف الخاص بايتات المصدر. نقل المصدر أو سحب إذنه قد يمنع إعادة فتح الوسائط.
- لا تغيير لعقد v1 أو محرر الويب. التوقف هنا للمراجعة، لا بدء لحزمة الطبقات المتعددة.
