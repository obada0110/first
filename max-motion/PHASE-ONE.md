# MAX EDITOR — تقرير قبول المرحلة الأولى

**النتيجة:** بُني APK تجريبي وشُغّلت شاشة الإعدادات واختُبر تبديل اللغة على **محاكي Android API 35 ‏(x86_64)**. لم يُختبر هاتف فعلي. هذا أساس Android لنفس مشروع MAX EDITOR، وليس نقلًا لمزايا محرر المتصفح إلى APK.

## الفحص والحدود

- ملفات محرر المتصفح ومنظومته الاختبارية في `max-motion/`، ونسخته المنشورة في `docs/max-motion/`. مضيف Android في `door-demo/` يخص مشروعًا آخر. لم تتغير ملفات المحرر المنشور ولم تُحذف وسائط المستخدم.
- بيئة العمل المحلية Linux x86_64: معالجان منطقيان، نحو 3.8 GiB RAM و18 GiB مساحة متاحة عند الفحص. لا Android SDK أو `adb` أو محاكي أو جهاز USB ظاهر. الموجود Java Runtime 25 وليس JDK بناء كاملًا؛ لا Flutter/Dart جاهزين ولا Gradle عالمي.
- نجح `preflight.py` محليًا. تنزيل مصدر Flutter من GitHub نجح، لكن تهيئة Dart من خادم Flutter وتنزيل توزيع Gradle من خادمه تعذّرا محليًا؛ لذلك لم ينجح البناء المحلي. لا تمثل هذه القياسات مواصفات هاتف المالك أو حاسوبه.

## إثبات التنفيذ

في [التشغيل المعتمد](https://github.com/obada0110/first/actions/runs/44882935360) عند المراجعة `42cd741` نجحت الخطوات التالية على مشغّل مستضاف: `flutter pub get`، `flutter gen-l10n`، `flutter analyze`، `flutter test`، `flutter build apk --debug` ثم اختبار تكامل Android. [الأثر القابل للتنزيل](https://github.com/obada0110/first/actions/runs/44882935360/artifacts/14698683247) أرشيف يحتوي على APK للتصحيح وملف قفل الاعتماديات، وليس إصدار متجر. أخفق [التشغيل السابق](https://github.com/obada0110/first/actions/runs/44882466820) عند بناء APK ولم يصل إلى المحاكي؛ لم يُثبت سبب الإخفاق الأول. أضفنا عرض خطأ البناء في نتائج CI لتسهيل تشخيص أي تكرار.

- **التعريب:** `mobile/lib/l10n/app_{ar,en}.arb` و`mobile/l10n.yaml` مصدر نصوص الواجهة. العربية الافتراضية، والإنجليزية اختيارية. قائمة اللغات منشأة من اللغات المولّدة لا من قائمة يدوية داخل الشاشة. تحقق اختبار Widgets من RTL → LTR → RTL ومن التعامل مع تعذّر الحفظ. تحقق اختبار المحاكي من اتجاه الواجهة وقراءة الإعداد المكتوب عبر Kotlin بعد التبديل.
- **البنية:** `mobile/lib/app/` للتركيب والتحكم، `lib/features/settings/` للشاشة وعقد التخزين، و`lib/platform/` مع `mobile/android/` لمحوّل Android وحفظ اللغة في تخزين خاص. `test/` و`integration_test/` و`tool/` و`.github/workflows/max-editor-foundation.yml` للفحص المتكرر. راجع [تعليمات التشغيل والقرارات المعمارية](mobile/README.md) للنسخ المطلوبة وحدود Media3 وMediaCodec وMediaMuxer وOpenGL ES مستقبلًا.
- **المتبقي:** اختبار هاتف فعلي، وتجهيز جهاز تطوير محلي عند الحاجة (Flutter 3.38.3 مع Dart، JDK 17، Android SDK 36 وأدواته؛ Gradle مرفق عبر Wrapper). لا يوجد Backend أو محرك مونتاج جديد أو توقيع تجاري. لا انتقال للمرحلة الثانية دون موافقة.
